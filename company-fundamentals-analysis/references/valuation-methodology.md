# 估值方法

估值是对假设的结构化表达，不是单点预测。所有方法都以同一基准日、币种和股份口径为准。

## 1. DCF

非金融企业优先使用 FCFF：

`FCFF = EBIT × (1-T) + D&A - Capex - ΔNWC`

`终值 = 第 N 年 FCFF × (1+g) / (WACC-g)`

`股权价值 = 预测期 FCFF 现值 + 终值现值 - 净债务 - 其他优先索取权 + 非经营资产`

`每股价值 = 股权价值 / 完全稀释股份数`

约束：

- `WACC > 永续增长率`；永续增长率不得无解释地高于长期名义经济增长；
- 显性预测期通常为 5–10 年，应与竞争优势期匹配；
- 收入增长、利润率、税率、再投资和资本周转应彼此一致；
- 终值占企业价值过高时，扩大敏感性并降低结论置信度；
- 对周期公司使用中周期利润/现金流，不从景气峰值机械外推；
- 金融企业优先使用股利折现、剩余收益或适合其资本监管的模型。

至少给出保守/基准/乐观三种情景及 WACC × g 二维敏感性。`scripts/dcf_valuation.py` 可复算给定 FCF 路径，但不会替代对假设的论证。

`安全边际 = (内在价值 - 当前价格) / 内在价值`

同时报告从当前价到内在价值的潜在回报：`内在价值 / 当前价 - 1`。两者分母不同，不得混用。

## 2. 相对估值

选择可比公司时说明业务结构、客户、地域、成长、利润率、资本强度和周期位置。至少使用两类倍数：

- PE：适合盈利稳定、会计口径可比的公司；
- PB：适合资产驱动或受资本约束行业，同时结合 ROE；
- PS：只在利润暂不稳定但单位经济可解释时使用；
- EV/EBITDA：适合资本结构不同的非金融公司，但不能忽略资本开支。

展示当前值、可比中位数、自身 5–10 年历史分位和隐含价格。历史分位需防止商业质量或利率环境发生结构变化。

## 3. PEG

`PEG = PE / 未来 3–5 年规范化净利润年复合增长率(百分数)`

例如 PE 20 倍、增长 20%，PEG 为 1。只有 PE 和增长均为正、增长可持续且口径匹配时使用。周期峰值、扭亏、高杠杆或增长高度不确定时，PEG 仅作旁证或不使用。

## 4. 机构观点

列出机构、发布日期、评级原文、目标价、预测年度 EPS/盈利和相对基准。对旧于最近重大财报或重大事件的报告标为过时。机构观点是市场预期证据，不是内在价值真值。

## 5. 价格区间与行动条件

- 安全边际买入价：由保守或基准内在价值乘以所需折扣得到，并说明折扣依据；
- 合理价值/目标卖出价：基于基准或乐观情景、实现期限和预期年化回报；
- 止损：优先写基本面失效条件，如份额、毛利率、ROIC、客户流失或治理事件。若给价格止损，说明它是仓位/波动管理规则，不是价值判断；
- 买卖时机：围绕财报、产能、订单、行业价格、政策和估值分位设置观察窗口，不宣称精确择时。

最终结论同时展示估值区间、概率权重、预期持有期、股息、稀释和主要下行情景。
