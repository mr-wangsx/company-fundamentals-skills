# 财务口径

所有公式使用同一会计范围和币种。优先展示原始输入和计算过程，不只给结果。

## 1. 现金流

基础自由现金流：

`FCF = 经营活动现金流净额(CFO) - 购建固定资产、无形资产和其他长期资产支付的现金`

必要时补充企业自由现金流：

`FCFF = EBIT × (1 - 规范化税率) + 折旧摊销 - 资本开支 - 营运资本增加`

检查项：

- 5 年均为正的年份数、5 年 CAGR、均值、标准差/均值、最差年份；
- `CFO / 归母净利润` 与 `FCF / 归母净利润`；
- 应收、合同资产、存货和应付对现金流的贡献；
- 维持性与扩张性资本开支能否区分；不能区分时用总资本开支并说明其保守性；
- 票据、保理、供应链融资、资本化研发、资产处置等对现金转换的影响。

负数起点或符号变化时不计算 CAGR，改用逐年变化、绝对增量和周期均值。

## 2. ROE

首选口径：

`ROE = 归属于母公司股东的净利润 / 平均归属于母公司股东权益`

`平均权益 = (期初归母权益 + 期末归母权益) / 2`

同时对照公司披露的加权平均 ROE，并解释扣非与非扣非差异。对大额增发、回购、分红或并购，简单期初期末平均可能失真，可增加季度加权口径。

用杜邦拆解辅助判断：净利率 × 资产周转率 × 权益乘数。高 ROE 若主要由高杠杆或一次性收益驱动，不等同于高质量。

## 3. ROIC

基础口径：

`NOPAT = 调整后 EBIT × (1 - 规范化税率)`

`投入资本 = 归母权益 + 少数股东权益 + 有息债务 - 非经营性现金及现金等价物`

`ROIC = NOPAT / 平均投入资本`

披露以下判断：

- EBIT 是否剔除投资收益、公允价值、资产处置、减值转回等非经营项目；
- 租赁负债、永续债和资本化研发如何处理；
- 现金中有多少是经营必需，无法可靠区分时同时给出“扣全部现金”和“不扣现金”区间；
- 税率异常时采用多年度规范化税率，并解释法定与实际税率差异。

金融企业不宜机械使用工业企业 ROIC，应改用行业资本充足率、ROE、净息差、不良率等口径。

## 4. 盈利质量与资产负债表

至少检查：

- 毛利率、营业利润率、净利率与扣非净利率趋势；
- 应收和存货增速是否长期高于收入，账龄、减值和周转天数是否恶化；
- 商誉、资本化开发支出、在建工程、关联交易和或有负债；
- 短债覆盖、净债务、利息保障倍数、受限资金和担保；
- 审计意见、关键审计事项、会计政策/估计变更及前期差错更正。

## 5. 分红与回购

`现金分红率 = 当年普通股现金分红 / 归母净利润`

`股息率 = 对应年度每股现金分红 / 选定基准股价`

必须说明股息率分母使用年末价、除权日前价还是当前价。回购只有在注销或真实减少稀释时才等同于股东回报；员工激励回购需单列。五年累计视角同时展示分红、回购、增发和可转债融资。
