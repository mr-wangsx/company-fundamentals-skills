# 研究与证据规范

## 1. 来源优先级

按以下顺序检索并引用；高层级来源与低层级来源冲突时，以可审计的原始披露为基准并解释差异。

1. 交易所、监管机构、法定信息披露平台、定期报告、临时公告、审计报告；
2. 政府统计、司法/工商/专利等官方数据库、行业协会正式统计；
3. 公司官网、投资者关系材料、业绩会原文、招股书和可持续发展报告；
4. 有方法说明的金融数据库、券商/评级机构报告、可核验研究论文；
5. 主流新闻、访谈和聚合平台。

对于 A 股，优先回到巨潮资讯及上交所、深交所或北交所原始公告。公司材料可证明“公司说过什么”，但市场份额、竞争优越性和客户评价应尽量寻找独立证据。

## 2. 时间与可比性

- 报告显式列出：研究执行日、最近收盘交易日、最新财报期、最近完整财年、股东披露期。
- 不把累计季度数与单季度数、年报与 TTM、预告/快报与审计数混用。
- 横向比较必须统一币种、税制、会计准则、财年、企业价值/股权价值和业务范围。
- 历史价格与股本要处理分红、送转、拆并股；当前估值使用最新可得稀释股份数。

## 3. 证据记录格式

每条关键证据至少保存：

| 字段 | 要求 |
|---|---|
| 主张 | 可单独判断真伪的完整句子 |
| 数值 | 原值、单位、币种、期间 |
| 口径 | 合并/母公司、归母/全口径、审计状态等 |
| 来源 | 文档标题、发布主体、发布日期、链接 |
| 定位 | 页码、章节、表名或网页段落 |
| 性质 | 事实/公司口径/第三方估计/计算/判断 |
| 置信度 | 高/中/低及原因 |

引用必须直接支持紧邻的结论。搜索摘要只能用于发现来源，不能作为最终证据。

## 4. 行业与竞争

- 市场规模和市占率必须说明产品边界、地区、年份、按收入还是出货量、含税与否。
- 梯队划分给出判据，避免用“龙头”“领先”替代量化比较。
- 客户与供应商仅列公开可验证者；年报未披露名称时不得反向猜测。说明前五大占比、关联方和集中度趋势比猜名单更重要。
- 专利数量需区分申请/授权、发明/实用新型、有效/失效及与主营的相关性。质量可参考专利族、引用、剩余期限和产品转化。

## 5. 当前市场数据与机构观点

- 当前价使用已完成交易日的官方或高质量行情，写明日期、收盘价、币种和是否复权。
- 十大流通股东是定期披露快照，不是实时持仓。对机构合并时保留产品明细，避免重复计算。
- 机构目标价需能核验机构、报告日期、分析师、预测期和币种。只汇总在当前信息集下仍有参考意义的报告，报告数量不足时如实说明。
- 评级用语不可直接平均；先映射到统一层级，并保留原评级。

## 6. 冲突与缺失处理

- 数值冲突先检查单位、期间、版本、合并范围和修订公告，再判断来源质量。
- 无法解决时并列数值并做敏感性分析；不得选择更符合结论的那个。
- 未披露、未找到和不存在是三种不同状态。只有可靠来源明确为零或不存在时才能写“无”。
