# 证据与核查协议

## 1. 核查对象

先创建主张清单，而不是直接评价整份报告。优先级由“对结论的影响 × 出错概率 × 验证可行性”决定。

高影响主张通常包括：收入/利润/现金流、ROE/ROIC、市场份额、核心客户、专利或牌照、管理层履历、主要股东/机构持仓、当前价格、DCF 假设、目标价和风险触发点。

## 2. 来源层级

1. 交易所、监管机构、法定披露、审计报告；
2. 政府/司法/专利/工商记录及行业协会统计；
3. 公司正式公告、官网和业绩会材料；
4. 有方法说明的数据商、券商/评级机构研究；
5. 新闻、访谈、聚合站与社交内容。

搜索结果摘要不能作为证据。公司材料只能直接证明其披露内容，不自动证明比较性宣传或因果结论。

## 3. 主张状态

| 状态 | 定义 |
|---|---|
| 已验证 | 独立原始证据在相同口径与期间下直接支持 |
| 大体支持 | 方向成立，但精度、范围或措辞需收窄 |
| 有冲突 | 可靠来源之间存在尚未解释的差异 |
| 错误 | 原始证据或复算明确否定 |
| 过时 | 在原截止日可能成立，但已被更新披露替代 |
| 不可验证 | 公开证据不足，既不能证实也不能证伪 |

任何“核查通过”都必须对应已验证主张。不可验证项不得计为通过。

## 4. 数字复核顺序

1. 核对主体、期间、币种和单位；
2. 核对报表、附注、修订公告和审计状态；
3. 核对合并范围、母公司或普通股股东口径、累计/单季和平均/期末余额；
4. 记录原始输入并独立复算；
5. 将差异拆为数据差异、公式差异、四舍五入或无法解释；
6. 评估差异是否改变评级、估值或风险判断。

默认数值容差可用绝对差与相对差的较大者，四舍五入项目通常允许 0.5%–1%；估值模型不应因为复算一致就判定合理，还要审计假设。

## 5. 常见错配

- 数量级和币种，例如元/千/百万/亿、本币/外币；
- 当季/累计，年报/TTM，预告/快报/审计数；
- 净利润/归属于母公司或普通股股东净利润/经调整净利润；
- 经营现金流/自由现金流；
- 期末权益/平均权益；
- 总股东/流通股东/机构申报，持股数/占总股本/占流通股；
- 总市值/企业价值；基本股/稀释股；
- 申请专利/授权专利/有效专利；
- 公司定义市场/第三方定义市场；出货量份额/收入份额。

## 6. 覆盖率与意见类型

报告覆盖率至少披露：已核查高影响主张数/高影响主张总数，以及所有抽样主张数/识别主张总数。

- 无保留：高影响主张均有充分证据，错误不改变结论；
- 有保留：存在重要不可验证或局部错误，但可修正；
- 否定：关键事实或模型错误足以推翻主要结论；
- 无法表示：缺少核心资料或访问受限，无法获得足够证据。

审计意见不是法定审计意见，应明确其基于公开信息。
