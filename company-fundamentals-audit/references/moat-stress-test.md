# 护城河压力测试

目标是先建立最强正面案例，再主动寻找能推翻它的证据。阈值为启发式起点，应按行业、周期和会计特征调整，不能跨行业机械套用。

## 第一轨：正向验证

### Step 1：长期财务成绩单

尽量观察 10 年，并至少覆盖一个下行周期：

| 维度 | 启发式检验 | 必查反例 |
|---|---|---|
| ROIC | 长期高于合理 WACC，10 年均值通常高于 12%更有说服力 | 连续下降、并购商誉或低税率虚增 |
| 毛利率 | 相对稳定或提升，波动有业务解释 | 产品降价、原料转嫁失败、会计重分类 |
| FCF | 多数年份为正，周期累计 FCF/净利润接近或高于 1 | 营运资本透支、资本开支不足、保理 |
| 周期穿越 | 下行期份额、利润或现金流优于同行 | 仅受益于行业景气或补贴 |
| 提价弹性 | 提价后销量/留存未显著恶化 | 缺乏真实量价数据、渠道压货 |

“达标 4 项”等分数只用于组织证据，不自动生成结论。

### Step 2：护城河物理结构

| 类型 | 核心问题 | 可信信号 |
|---|---|---|
| 品牌/心智 | 去掉品牌后仍能维持价格吗 | 长期溢价、复购与份额同时稳定 |
| 网络效应 | 每增加一个参与者是否提高其他参与者价值 | 双边活跃度和留存形成自强化 |
| 转换成本 | 客户更换要承担多少钱、时间和业务风险 | 深度嵌入、认证周期、数据/流程迁移成本 |
| 成本/工艺 | 规模、良率、供应链或资源能否被追平 | 单位成本领先且差距可持续 |
| 特许/稀缺资源 | 优势来自何种受限资格或资源 | 供给约束真实，监管收益上限可接受 |

额外检查知识产权、产品性能、客户依赖、主营利润集中度和市占率。对每种候选护城河回答：竞争者若有充足资金，仍需要什么不可购买的时间、数据、信任、组织或制度条件？

### Step 3：动态可持续性

- 留存利润能否继续以高 ROIC 再投资；
- 文化和激励是否支持长期质量、客户价值与自我颠覆；
- 十年后需求、价值链和技术路线是否仍在；
- 第二曲线是否已有客户、收入、单位经济或工程里程碑，而非叙事。

## 第二轨：逆向证伪

### Step 4：七维扫描

| 维度 | 重点寻找的致命信号 |
|---|---|
| 财务慢性病 | ROIC 连降、应收/存货长期快于收入、CFO 弱于利润、审计异常 |
| 客户背叛 | 提价后流失、集中客户转单、获客成本上升、留存/使用下降 |
| 竞争入侵 | 异类模式、份额流失、对手良率/毛利追平、价格战 |
| 技术过期 | 技术路线被替代、标准迁移、价值链被软件化或模块化 |
| 组织腐朽 | 核心离职、不相关多元化、治理冲突、激励短期化 |
| 制度抽薪 | 反垄断、集采、补贴退坡、环保/出口/行业标准变化 |
| 估值泡沫 | 极端历史分位、终值主导、增长假设隐含份额不可能、单边共识 |

每项标注 `安全/观察/警报`、证据质量、早期指标和升级条件。

### Step 5：红队演练

假设必须在明天建立空头论点，提出最强的三条可验证论据。每条包含机制、证据、时间窗口和预期财务影响。再由蓝队用独立证据反驳，并评为：

- 有效反驳：直接处理核心机制；
- 部分反驳：只降低概率或影响；
- 无效反驳：转移话题、诉诸历史或重复管理层口号。

### Step 6：预验尸

假设五年后护城河坍塌且股价大幅下跌，倒推最可能的三个死因。对每个死因列出概率、影响、因果链、当前早期信号和未来 1–3 年可观测阈值。

## 评级

企业护城河与报告证据质量分开评级：

- A：优势深且可持续，长期财务与独立证据支持，红队核心论据被有效回应；
- B：存在真实优势，但至少一个关键机制或持续性仍不确定；
- C：优势浅、依赖外部条件或已有侵蚀，多项红旗未被回应；
- D：所谓优势主要是周期、补贴、会计或叙事，关键前提已被否定。

同时给出高/中/低置信度。证据不足时降低置信度，不武断上调或下调评级。

## 伪护城河清单

专利数量、先发、高研发、重资产、高资本开支、政府补贴、短期高增长和管理层愿景都不是单独充分条件。必须证明它们已转化为客户价值、价格/成本优势、持久份额和超额资本回报。
